Codex Limit Companion 是原生 macOS 菜单栏应用，监控 Codex 五小时与每周额度。额度监控 → 等待恢复 → 向指定会话发送继续指令，每次触发都有记录。

下载 macOS 版 ↓v0.0.4 · Apple Silicon · macOS 14+

就在菜单栏里。

点击图标展开面板，点击外部收起。没有需要常驻桌面的独立窗口。

应用实拍，额度为拍摄时的数据；日志展示尚未触发自动恢复的空状态。点击图片可查看大图。

把注意力留给正在做的事。

一眼看清额度
图标的填充高度表示剩余比例。打开后查看短周期、每周额度、重置倒计时，以及预计恢复提示。
只继续你选中的会话
搜索并选择最近的任务，设置好继续消息。额度从耗尽恢复为可用后，向这些会话定向发送，不必切换前台窗口。
有记录，才放心
每次自动恢复都记录触发时间、目标会话、消息与发送结果。本机保留最近 300 条，“已排队”与“执行完成”明确区分。
轻轻打开，安静运行
原生 SwiftUI，macOS 26 上使用 Liquid Glass。会话按需加载并缓存，后台每 60 秒检查一次额度。

三步，准备下一次继续。

  1. 安装与登录。把应用放入 Applications，安装并登录支持 app-server 和 queue 的 Codex CLI。
  2. 选好任务。从顶部图标进入「会话」，选择要恢复的任务；到「设置」填写继续消息，开启定向发送。
  3. 保持运行。应用先观察到额度耗尽，再等待恢复。触发后，到「恢复日志」查看结果。

通过 codex queue 向指定会话发送消息，无需保持 Codex 在前台，不模拟键盘输入，也不需要辅助功能权限。

FAQ / 常见问题

How to automatically resume Codex after a rate limit reset?

Install the macOS app and sign in to a Codex CLI that supports app-server and queue. Select existing sessions, enable automatic sending, and keep the app running. After observing a restriction and confirming quota recovery, it queues your continuation message for each selected session.

How to monitor Codex 5-hour and weekly usage limits?

The menu bar icon shows remaining quota. Open the panel for reported 5-hour and weekly usage limits, reset times, and countdowns. The app checks every 60 seconds; available windows depend on what Codex reports.

Can I resume multiple existing Codex sessions?

Yes. Select multiple sessions and configure a continuation message. Each confirmed recovery sends once per selected thread, without creating a new task or typing into the foreground app.

Codex 额度用完后，如何自动继续任务？

选择目标会话，在设置中开启恢复后自动发送，并保持应用运行。剩余 ≤1% 或服务端受限时进入等待；所有监控周期恢复到 ≥5%，连续两次有效检查确认后才发送。它会推动原会话继续，不保证任务最终完成。

额度恢复后，一定会马上继续吗？

应用每 60 秒检查一次，需要先观察到额度耗尽，再确认所有监控周期剩余至少 5%，且两次有效检查间隔至少 45 秒。休眠、网络故障或额外服务端限制可能延迟触发。预计恢复时间只是估计；启动时额度已经可用，不会补发消息。

日志里的“已排队”意味着任务完成了吗？

不意味着完成，只表示 Codex 接受了消息。失败不会自动重试。0.0.4 已移除前台模拟输入，旧版历史记录仍可查看；日志不能补录安装前的事件。

为什么 Mac 顶部没有图标？

先检查系统「菜单栏」设置和菜单栏管理工具。macOS Tahoe 可能将开发期间启动的应用错误关联到 ChatGPT/Codex 的菜单栏开关，本应用已开启时也请检查这两项。开启关联项是临时解决办法，不会清除系统关联。

我的数据放在哪里？

设置和恢复日志保存在本机，凭据由本机 Codex CLI 管理。额度查询与消息发送仍通过 Codex 服务完成。本介绍页不使用追踪脚本、广告或第三方字体。
